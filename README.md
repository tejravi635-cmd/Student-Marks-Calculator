# Student Marks Calculator

My first Python project!

## Description
A simple Python program that calculates student marks,
percentage, grade, and pass/fail result.

## Features
- Accepts student name
- Accepts marks for three subjects
- Calculates total marks
- Calculates percentage
- Displays grade
- Displays pass/fail result

## Technologies Used
- Python 3

## How to Run
1. Download student_marks.py
2. Open it using Python 3
3. Enter student details and marks
4. View the result
